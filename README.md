  ## ⚡ How I work

  🏗️ **I write production code, not scripts.** Backend services, frameworks, and packages with real consumers — designed to be maintained by other people, reviewed, versioned, and released on a cadence. TypeScript and Python primarily; Java, Apex, SQL, and Terraform where the job calls for it.

  📈 **I work at scale.** Multi-tenant systems, hundreds of millions of records, distributed workers and queues. Scale changes which designs survive — in-memory assumptions break, retries turn into stampedes, and the cost of a bad schema decision compounds. I've been on the wrong side of that enough times to design for it up front.

  🔍 **I debug across the whole stack.** Most real failures don't live inside one system — they live in the seams between them. I'll trace a problem from the UI through the API, the queue, the container, the IAM policy, and into the database, and I'd rather build a controlled experiment that confirms a root cause than ship a plausible guess.

  🚀 **I own the deploy path.** Kubernetes, Terraform, GitOps, CI/CD pipelines. Writing the code is half the job; making it deployable, observable, and safe to roll back is the other half, and I don't hand that off.

  🤖 **I build with LLMs, carefully.** Agentic systems running in production with the guardrails that make them safe — confidence gates, scoped permissions, human review before anything merges. The engineering is in the constraints, not the prompt.
