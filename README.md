## ⚡ How I work

🏗️ **I build test infrastructure as production software.** Frameworks, harnesses, and simulator services with real consumers — versioned, reviewed, released on a cadence, and designed to be maintained by someone other than me. Page-object models, custom fixtures, network interception, multi-auth state. Not a folder of scripts that only the author can run.

📈 **I test at scale.** Multi-tenant systems, billions of records, distributed workers and queues. Scale changes which tests survive — hardcoded fixtures rot, retries turn into stampedes, and shared state across parallel workers becomes the flakiness. I design for it up front: per-worker namespacing, variance-bounded assertions, seeded data with guaranteed teardown. Load and stress testing with k6 and Locust, including autoscaler validation and non-deterministic tool-call paths.

🔍 **I debug across the whole stack.** Most real failures don't live inside one system — they live in the seams between them. I'll trace a problem from the UI through the API, the queue, the container, the IAM policy, and into the database, and I'd rather build a controlled experiment that confirms a root cause than ship a plausible guess. A failing test is the beginning of the investigation, not the end of it.

🚀 **I own the deploy path.** Kubernetes, Terraform, GitOps, GitHub Actions. Writing the tests is half the job; making them run on every deploy across parallel shards, report somewhere people actually look, and gate a release is the other half — and I don't hand that off.

🤖 **I build AI-first quality tooling.** LangGraph agents wired to Jira, Confluence, and GitHub for test generation; selector auditing; and an autonomous test-repair agent shipped to production after security review. The engineering is in the constraints, not the prompt — confidence gating, per-run fix caps, scoped permissions, and a hard never-auto-merge rule.

🧭 **I set direction and grow people.** Owning an automation roadmap rather than a backlog: defining the reusable test standard other teams adopt, pushing quality left by agreeing selector conventions with developers before a feature ships, and mentoring SDETs.
